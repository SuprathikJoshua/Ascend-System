# Prep Dashboard
Local-first interview prep tracker built with Next.js 16, React, TypeScript, Tailwind v4, and Dexie.
Run `bun install` to install dependencies.
Run `bun run dev` and open http://localhost:3000.
Dashboard: daily DSA and web-dev targets, streak, deadlines, and JSON backup reminder.
DSA: phase gameplan, topic progress, Graph checklists, and spaced revision tasks.
Web Dev: 61 roadmap topics across phases 0–8 with practical proof requirements.
Settings: schedules, deadlines, JSON export/import, and placeholder-proof cleanup.
App data stays in browser IndexedDB; there is no account or cloud sync.
Use Settings > Data Management to export a JSON backup before resetting or moving browsers.
